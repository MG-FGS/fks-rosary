FKS Rosary V1.3

Extract the ZIP and copy the app files to your GitHub Pages publishing folder. For a site published from the repository root, place index.html and the other app files at the root of fks-rosary.

Changes: FKS crown branding, larger bilingual Pray with Mary/Oremos con María title, detailed rosary with animated gold active bead, blue completed beads, keyboard accessibility and reduced-motion support.

Progress remains stored under the original browser localStorage keys to preserve existing sessions.

Note: GitHub Pages may take a few minutes to deploy. Close/reopen the app or refresh twice if the old service worker is still cached.

V1.3 aligns the numbered Hail Mary beads and the opening and closing prayer markers with the prayer sequence.
